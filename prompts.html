Prompt Forge

Internal tool — assembles Warpack art prompts from the studio templates. No AI, no waiting: the templates ARE the knowledge.

—

Unit sprites: paste into PixelLab, canvas 252×252, transparent background, 8-direction idle (South frame minimum — the game mirrors the rest).
Icons/portraits/arenas: paste into Midjourney. Templates live in Warpack/docs/ — if a template changes there, update this page.
